# Dev Roadmap

Minha jornada prática de desenvolvimento.

## Objetivo

Construir conhecimento e experiência prática suficientes para atuar como **Desenvolvedor Fullstack Jr.**

O foco deste repositório é transformar conhecimento teórico em capacidade real de desenvolvimento.

---

## Ponto de partida

Atualmente possuo uma boa base conceitual em:

* Lógica de programação
* Algoritmos
* Estruturas básicas
* Orientação a objetos
* SQL
* APIs REST
* HTTP
* Git
* Arquitetura web

Meu principal ponto de desenvolvimento é **prática de programação**:

> Entender um problema → desenvolver uma solução → executar → encontrar erros → corrigir → refatorar.
