# Fundamentos

1. Teoria
   1.1 O que é JavaScript?

JavaScript (JS) é uma linguagem de programação criada originalmente para adicionar comportamento às páginas web.

Hoje ela é uma linguagem de propósito geral e pode ser utilizada para:

    Front-end
    Back-end
    APIs
    Automação
    Scripts
    Aplicações desktop
    Aplicações mobile
    Ferramentas de linha de comando
    Servidores

Um ponto importante:

    JavaScript é a linguagem. Node.js é um ambiente que executa JavaScript fora do navegador.

1.2 Onde JavaScript roda?

Existem dois ambientes fundamentais para você dominar agora.

Browser

O navegador possui um motor JavaScript capaz de interpretar e executar código JS.

1.3 Node.js

O Node.js permite executar JavaScript fora do navegador.

Portanto:

JavaScript
├── Browser
│ ├── DOM
│ ├── eventos
│ ├── APIs do navegador
│ └── interface web
│
└── Node.js
├── arquivos
├── processos
├── rede
├── servidores
└── terminal
