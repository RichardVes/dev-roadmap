# prefixo

    study:     conteúdo/exercício estudado
    feat:      implementação de uma funcionalidade real
    fix:       correção de código/exercício
    refactor:  reorganização sem mudar comportamento
    docs:      documentação/README/anotações
    chore:     configuração/manutenção do projeto

# commits

    <tipo>: <tecnologia> - <assunto> - <ação>
    ex:
        study: javascript - variaveis primitivas - exercicios

## exemplo geral de commits

    ex:
        study: javascript - variaveis primitivas - exercicios
        study: javascript - operadores - exercicios
        study: javascript - condicionais - exercicios
        fix: javascript - corrige exercicio de operadores
        docs: atualiza roadmap de javascript
